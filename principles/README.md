# Governing scientific and engineering principles

This directory specifies the reasoning standards for every Lycoris scientific model:

1. First principles and conservation.
2. Fermi bounds and dimensional sanity checks.
3. Bayesian inference with accountable priors and calibrated evidence.
4. Validation, falsification and reproducibility.
5. Provenance, uncertainty and missing-data honesty.
6. Safety and decision integrity.
7. Modular dependencies, state transitions and stable contracts.

Principles constrain *how* a model may be justified. They do not imply that any particular model has been verified.
