# First-principles reasoning

Start with physical definitions, state variables and conserved quantities before choosing a heuristic.

For each model: identify what changes, what can flow into/out of the system, the reference frame, units, independent constraints and intended operating domain. Prefer state transitions and explicit mass/energy balances over unrelated dashboard multipliers.

Disentangle a mathematical identity from an empirical calibration. Proving a computational invariant does not validate a Mars EVA hazard threshold.
