# Validation, verification and falsification

A reliable scientific claim needs different tests:
- dimensional and conservation invariants;
- independently derived numerical checks and analytical test cases;
- geospatial alignment and source metadata validation;
- withheld-data or external reference comparisons where available;
- uncertainty, sensitivity and resolution-convergence stress tests;
- invalid endpoint, missing-data, unreachable-route and missing-return failures;
- reproducible versioned inputs, outputs and processing steps.

Classify each result as untested, synthetic-verified, source-validated, or empirically calibrated. Never conflate these stages.
