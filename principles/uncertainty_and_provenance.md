# Evidence lineage and uncertainty

All outputs must be classified as measured, derived, assumed or unknown, with source identifiers, transformation histories, spatial/time applicability, units and quality flags.

Differentiate epistemic uncertainty (limited knowledge) from aleatoric variation (modeled variability). Preserve shared/correlated uncertainties such as image registration errors. Track the exact source and model versions supporting a reported number.

Changes to a dataset or parameter invalidate only the dependent results, as established by the model dependency graph.
