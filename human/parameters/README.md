# Human parameter declarations

**1,691 named candidate human variables in 56 domain files across six groups.** This is a *research inventory*, not a calibrated 1,691-equation physiological simulator.

See `INDEX.json` for counts and file paths. All records have `binding_status=declared_unbound` until actual source observations or appropriately justified scenario models are attached.

Source leads reference NASA/ESA research portals and standards, not a source proving each quantity can be measured in a suited astronaut or predicted under Martian gravity.

`kind=observable`: physical or laboratory observation possible in **a specified measurement context**, not necessarily on Mars. `kind=latent`: hidden state only inferable through a calibrated model. `kind=clinical_assessment`: qualified clinician or validated self-report instrument. `kind=derived`: requires defined input equations and numerical validation. `kind=scenario_input`: hypothetical, provided by mission designers.

Use `PRIORITY.md` to select a scientifically defensible initial simulation. Use `../models/SUIT_HANDOFF_CONTRACT.md` before connecting equipment outputs.

Individual medical, mental health and reproductive data must never be made public without appropriate protection, lawful consent and necessity.
