# Source catalog

This directory records scientific source metadata and acceptance checks **before** raw measurements enter any model.

A source is accepted only when its identity, appropriate rights, units, domain, coordinate/time support, quality controls, and reproducible retrieval can be established.

Every adopted source gets an individually versioned record following `SOURCE_TEMPLATE.md`. Candidate products listed in `SOURCE_REGISTER.md` are not automatically validated or approved NASA Space Apps Resources-tab sources.
