# Units, dimensions and invariants

Specify a common internal system: SI dimensions for distance, time, mass, energy, power, pressure and temperature; explicit conversion for presentation.

Guard against: m vs km, degree vs radian, metres of elevation vs areoid/radius, Earth hours vs sols, UTC vs LMST, O2 mass vs gas volume at unknown reference conditions, absorbed dose in Gy vs equivalent/effective dose in Sv.

Models must declare input and output dimensions and reject impossible or undefined conversions. These checks precede physical plausibility claims.
