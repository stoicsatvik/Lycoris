# Mars environmental models

Responsibilities: solar geometry and daylight, historical atmospheric context, dust scenarios, thermal environment, radiation type/units and environment-driven mission constraints.

Separate observed samples, modeled historical interpolation, future scenarios and real-time monitoring. MEDA RDS optical radiation is not a substitute for Curiosity RAD ionizing dose. Gale measurements cannot be presented as Jezero measurements.

No physical safety thresholds are asserted without independent support.
